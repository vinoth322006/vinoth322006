<details>
<summary><b>🔍 How MedScholar works (click to expand)</b></summary>
<br>

```mermaid
flowchart LR
    Q["Question in plain English"] --> E["MedCPT query encoder"]
    E --> F["FAISS IVF-PQ index<br/>36M papers, 4 GB"]
    F --> R["Top matching papers"]
    R --> API["FastAPI search service"]
    API --> UI["React web app"]
    API <--> C[("Redis cache")]
    UI <--> DB[("PostgreSQL<br/>users and bookmarks")]
```

The 36 million paper vectors took over 150 GB. Compressing them with **IVF-PQ quantization** brought the index down to 4 GB with little accuracy loss, so the whole system runs on one affordable AWS EC2 server and answers in under 1.5 seconds.

</details>
